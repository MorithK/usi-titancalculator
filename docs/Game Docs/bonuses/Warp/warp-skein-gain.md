## Mapping notes (2026-11-26)

The [wiki's Tether Warp section](https://spaceidle.game-vault.net/wiki/Warp_Drive) states that **Skein is granted after a completed charge**, and that each cleared difficulty above the starting difficulty increases Skein gain by **×1.35**. The displayed **×5.31** is a snapshot of the named *global Warp Skein Gain* stat; it must not automatically be equated to total Skein per individual Warp cycle.

For effective Skein per cycle, investigate each Warp's base amount, cleared difficulty count, global Skein modifier and additional location-specific bonuses. Preserve the distinction from Residuum gain, which the wiki says does **not** increase through the same difficulty scaling.
