## Game mechanics

Bases arrange buildings on grids. Buildings produce base materials, parts and components, or influence adjacent buildings. The wiki notes that component totals can provide system multipliers **on prestige**, so model layout and progression separately from bonuses currently applied.

## Calculator requirements

Import active layout, building levels/positions, resources, production, purchased slots and finalized/persistent upgrades where saved. Determine whether a hypothetical layout change changes *future* gains only or already-applied effective stats.
