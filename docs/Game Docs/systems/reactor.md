# Reactor

**Documentation status:** Initial source-grounded outline. **Formula verification:** Incomplete.

**Primary reference:** [Unnamed Space Idle Wiki — Reactor](https://spaceidle.game-vault.net/wiki/Reactor). Additional observations come from the player's saved-game and bonus snapshots.

## Game mechanics

The Reactor converts **Void Matter into Void Power** and provides buffs to other systems. Wiki documentation describes separate Void Power generation, storage/capacity and Overdrive mechanics. The **Massive Reactor** upgrade changes how boosts are sustained; its early unlock rules may differ from the user's current Titan-era state.

## Observed modifier destinations

The user identified Reactor contributions to Veil Fragment Gain, Synth Speed, Warp Discharge Speed, Titan Battle, Compute Throughput, Resistance Rate, Specimen Gain, Fixture Speed, Shifted Fragment Gain, Discipline Mastery, Strata Expertise Gain and Capital Resource Gain.

These are **targets**, not already-verified source formulas. `Massive Reactor: Synth Speed` is observed in [Synth Speed](../bonuses/Synth/synth-speed.md) as ×7.25e8 for one captured save.
